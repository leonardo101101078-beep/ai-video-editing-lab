## 更新方式

1. 改 `index.html` 內容
2. 改頁首「最後更新」日期（`id="updated"`）
3. 在「更新紀錄」區塊和 `CHANGELOG.md` 各加一筆
4. 加案例：複製一個 `<article class="case">`；IG reel 用 `https://www.instagram.com/reel/<id>/embed`，FB reel 用 `https://www.facebook.com/plugins/video.php?href=<編碼後網址>`，本機影片放 `assets/`
5. `git commit -am "..." && git push`
